# Volta

An unofficial, bilingual (Arabic / English) fan site about the founding and history of Al-Ittihad Club, Jeddah — est. 26 December 1927.

Volta is not affiliated with or endorsed by Al-Ittihad Club. It uses no club crest or press photography.

## Structure

| File | Purpose |
|---|---|
| `index.html` | Page shell |
| `styles.css` | Design: club yellow and black, with a rawshan-lattice divider from old Jeddah |
| `app.js` | Renders the content and switches language (Arabic is the default) |
| `data/content.js` | All site text in both languages, the photo list and the sources — edit content here |

No build step: open `index.html` in a browser, or deploy the folder as a static site.

## Photos

Stadium photos load from Wikimedia Commons, which hosts only freely licensed media. Each photo on the site links to its Commons file page, where the author and licence are shown. If a photo fails to load, its frame shows the black-stripe pattern instead.
